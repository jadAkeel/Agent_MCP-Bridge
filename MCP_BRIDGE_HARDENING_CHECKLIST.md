# MCP Bridge Hardening Checklist

This is the single authoritative investigation checklist for the reliability and
security hardening effort. A subsystem is reopened only when a new test fails, a
reviewer supplies concrete new evidence, or a relevant code change invalidates
prior evidence.

Status values:

- `CONFIRMED-OPEN`: reproducible/evidence-backed and not fully fixed.
- `FIXED-PENDING-TEST`: code changed; required focused/current tests are not all green.
- `CLOSED-TESTED`: fixed and its focused regression passed on the current code.
- `DEFERRED`: intentionally outside the bridge boundary, with the reason recorded.
- `REJECTED`: concrete review finding was not reproducible against current code.
- `GATE-PENDING`: release/activation gate not yet run or not yet green.
